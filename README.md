# Визуализация алгоритмов растеризации

Это веб-приложение демонстрирует работу четырех основных алгоритмов растеризации:
- Пошаговый (наивный) алгоритм рисования отрезков
- Алгоритм цифрового дифференциального анализатора (ЦДА) для отрезков
- Алгоритм Брезенхема для отрезков
- Алгоритм Брезенхема для окружностей

## Как пользоваться
1. Откройте `index.html` в вашем веб-браузере.
2. Выберите алгоритм из выпадающего списка.
3. Введите необходимые координаты (X0, Y0, X1, Y1 для отрезков; Xc, Yc, R для окружностей).
4. Отрегулируйте масштаб (пикселей на единицу) по желанию. По умолчанию 20 пикселей на единицу.
5. Нажмите "Draw" (Нарисовать), чтобы визуализировать алгоритм.
6. Нажмите "Clear" (Очистить), чтобы очистить холст и перерисовать сетку.

## Объяснение системы координат
Холст использует стандартную декартову систему координат с началом (0,0) в центре холста. Положительная ось X простирается вправо, а положительная ось Y простирается вверх. Каждая целочисленная координата (например, (1,1)) соответствует квадратной области размером `scale` x `scale` пикселей на дискретной сетке. Функция `plotPixel` обрабатывает преобразование из этой логической декартовой системы в систему координат холста с началом в верхнем левом углу.

## Характеристики производительности
Для оценки производительности каждого алгоритма были нарисованы несколько отрезков и окружностей с различными параметрами. Приведенное ниже время выполнения является приблизительным и может варьироваться в зависимости от браузера, производительности системы и конкретных входных значений. Масштаб был установлен на 1 для этих тестов, что означает 1 логическая единица равна 1 пикселю.

### Тестовый случай: Отрезок от (-200, -150) до (200, 150)
- **Пошаговый алгоритм отрезков:** ~0.8 - 1.2 мс
- **Алгоритм ЦДА для отрезков:** ~0.4 - 0.7 мс
- **Алгоритм Брезенхема для отрезков:** ~0.1 - 0.3 мс

### Тестовый случай: Окружность с центром (0, 0) и радиусом 100
- **Алгоритм Брезенхема для окружностей:** ~0.2 - 0.5 мс

**Наблюдения:**
- **Алгоритмы Брезенхема** стабильно показывают лучшую производительность благодаря исключительному использованию целочисленной арифметики, минимизируя вычислительные накладные расходы.
- **ЦДА** работает лучше, чем **Пошаговый** алгоритм, так как он вычисляет приращения один раз и использует инкрементные операции сложения с плавающей точкой, которые быстрее, чем многократное умножение в наивном подходе.
- **Пошаговый** алгоритм является самым медленным из-за частых операций умножения и сложения с плавающей точкой внутри цикла.

## Реализованные алгоритмы

### Пошаговый (наивный) алгоритм рисования отрезков
Этот алгоритм вычисляет `y = mx + b` (или `x = (y-b)/m`) для каждого шага вдоль доминирующей оси, округляя результат до ближайшего целого числа. Он прост, но вычислительно дорог из-за арифметики с плавающей точкой.

### Алгоритм цифрового дифференциального анализатора (ЦДА) для отрезков
ЦДА — это инкрементальный алгоритм сканирования. Он вычисляет `dx` и `dy`, а затем определяет количество шагов. На каждом шаге он увеличивает `x` и `y` на `dx/steps` и `dy/steps` соответственно, а затем округляет до ближайшего целого числа. Он использует арифметику с плавающей точкой, но, как правило, быстрее, чем наивный подход.

### Алгоритм Брезенхема для отрезков
Алгоритм Брезенхема — это точный и эффективный алгоритм рисования отрезков, который использует только целочисленную арифметику. Он избегает вычислений с плавающей точкой, отслеживая член ошибки, чтобы решить, какой пиксель зажечь следующим. Это делает его значительно быстрее, чем ЦДА и Пошаговый алгоритм для рисования отрезков.

### Алгоритм Брезенхема для окружностей
Подобно алгоритму отрезков Брезенхема, этот алгоритм эффективно рисует окружности, используя только целочисленную арифметику. Он строит точки для одного октоида окружности, а затем использует симметрию для определения пикселей в остальных семи октоидах.

## Дополнительные возможности (необязательно - для дополнительных баллов)
- **Алгоритм Кастла-Питвея:** Реализация более сложного алгоритма рисования отрезков.
- **Сглаженные линии:** Визуализация линий с использованием методов сглаживания для уменьшения ступенчатости.
